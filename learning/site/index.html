Computational phonetics, one rhyme detector at a time

A self-contained course on NLP and computational phonology, taught through a single worked project: rhyme-schemer, a tool that reads hip-hop lyrics and surfaces their rhyme scheme — slant rhyme, assonance, and all. You read real modules, build the missing ones, and every concept arrives already attached to code that uses it.

For the linguistics-curious programmer: the phonology is taught from the ground up; the algorithms assume fluency in code but not a background in algorithm design. Start with how this course works — and if your phonetics is cold (or was never warm), the sounds refresher rebuilds it in twenty minutes, mostly by making you make sounds at your desk.
